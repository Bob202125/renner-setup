# Renner setup

Clone this repository or download its ZIP, then ask Codex to read START-HERE.md and complete the setup on your Mac. The actual installer, Obsidian plugins, annotation settings, utilities and iTerm configuration are included here.

Run `python3 install.py` after reviewing START-HERE.md. Installation refuses to overwrite an existing ~/utils folder; Codex can merge an existing setup deliberately with backups.
